# anantojha.github.io

Personal site. Plain HTML, CSS and JS; no build step.

- Edit content in `js/projects.js` (experience, projects, skills).
- `assets/Anant_Ojha_Resume.pdf` must be the public version, with no phone number.
- `assets/og-image.png` (1200×630) is the link-preview image.
- Deploy: push to `main`; Settings → Pages → Deploy from branch → `main` / root.
