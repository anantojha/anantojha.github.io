# anantojha.github.io

Personal site. Plain HTML, CSS and JS; no build step.

- Edit content in `js/projects.js` (search for `TODO`).
- Add `assets/Anant_Ojha_Resume.pdf` (public version, no phone number) and `assets/og-image.png` (1200×630).
- Deploy: push to `main`, then Settings → Pages → Deploy from branch → `main` / root.
- Custom domain: add a `CNAME` file, set DNS, enable Enforce HTTPS.
